Get started with Ads+

Use this quick guide to install the extension. A video tutorial can be added here later.

Quick setup guide
  1. 1
    Download the ZIP

    Choose Download Extension ZIP above and save the archive.

  2. 2
    Extract the archive

    Unzip it into a folder on your computer. Keep the extracted files together.

  3. 3
    Open extension settings

    In desktop Chrome, open chrome://extensions and enable Developer mode.

  4. 4
    Load the extension

    Select Load unpacked and choose the extracted folder containing manifest.json.

  5. 5
    Open Ads+

    Use the extension icon in your browser toolbar and review its available options.

This manual setup guide is for compatible desktop browsers. Chrome on Android does not support this standard desktop extension installation flow.
